# Home ↔ GitHub Bridge

## 定位

Google Drive 的「家」保存私人權威記憶、治理與核准證據；GitHub 保存可公開、可版本化、可搜尋、可測試的工程骨架與開源雷達。

## 雙向資料流

### 家 → GitHub

只允許輸出：

- 公開工程規格與介面。
- 不含個資與祕密值的工具登錄。
- 候選程式、測試、Manifest、SHA256 與回退說明。
- 經去識別化的需求摘要。

禁止輸出：

- API Key、Token、密碼、私鑰。
- 私人對話全文、家庭個資、未公開作品原稿。
- Google Drive 權威文件的未審核完整副本。

### GitHub → 家

可同步：

- 開源雷達快照。
- 候選工具評分與版本變動。
- Draft PR、CI、測試及供應鏈證據。
- 已核准封包的版本與 SHA256。

所有內容先進 `Memory Inbox`／候選區，未經核准不得升格為權威記憶。

## 新視窗啟動契約

每個新視窗先讀 `LIDIYA_START_HERE.md`，再完成：

1. 家的權威版本檢查。
2. `LATEST_SNAPSHOT.json` 時效檢查。
3. 以家中任務與硬體需求篩選候選。
4. 依評分政策輸出「忽略／觀察／沙盒評測／候選導入」。
5. 涉及安裝、正式寫入、模型下載、公開發布或實體控制時，要求逐次解鎖。

## 成長迴圈

發現 → 登錄 → 來源驗證 → 適配評分 → 沙盒 → 影子模式 → 候選封包 → 使用者核准 → 有限部署 → 實績評分 → 保留／回退／升級。

## 故障策略

- 家不可用：GitHub 只提供公開工程與最近快照，不重建私人記憶。
- GitHub 不可用：以家中最後核准清冊繼續，停止取得新工具。
- 雙邊版本衝突：停止升級，保留兩份證據並交由線上璃蒂雅與博玄裁決。
