# Lidiya Foundation

此目錄是璃蒂雅小窩的公開工程地基，不保存私人記憶或任何祕密值。

## 核心入口

- `../LIDIYA_START_HERE.md`：所有新視窗的啟動順序。
- `HOME_GITHUB_BRIDGE.md`：家與 GitHub 的邊界與同步方式。
- `governance/AUTHORIZATION_ACTIVE_20260723.json`：目前限定授權範圍。
- `open_source/registry.json`：官方開源來源清冊。
- `open_source/SEARCH_INDEX.json`：依需求與關鍵字搜尋候選。
- `open_source/EVALUATION_POLICY.md`：採用與風險評分規則。
- `local_body/`：localhost-only、只讀證據橋接候選。
- `config/model_providers.env.example`：不含祕密值的模型供應商設定範本。
